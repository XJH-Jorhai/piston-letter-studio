# Alphabet generation prompts

All atlases were generated with the built-in image_gen tool from the approved sticker references. No CLI generation or unrelated font substitute was used. Each atlas is a 7 × 2 layout with thirteen letters and one empty cell. Individual PNGs were prepared from atlas components; the original G, T, M, C and D assets are reused where present.
